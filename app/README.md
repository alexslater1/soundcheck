# app

Expo SDK 53 universal app (Android + web + admin console), TypeScript strict, Expo Router in `src/app`.

```bash
npm install
npm run lint && npm run typecheck && npm test   # what CI runs
npm start                                       # dev server; press w for web (http://localhost:8081, or via the edge on :8088)
npm run android                                 # dev build on the connected phone (expo run:android); prefer `make android`, which sets up adb reverse first
npm run export                                  # static web build → dist/
```

- `src/app/` routes only; logic in `src/features/*`; primitives in `src/components/ui`; tokens in `src/theme`.
- `src/api/http.ts` is the orval mutator; `src/api/generated/` is regenerated by `make openapi` — never edit it.
- `EXPO_PUBLIC_API_BASE_URL` (default `http://localhost:8088`) is the only runtime setting (`src/lib/env.ts`).
- Styling is a `StyleSheet` token system (dark first) rather than NativeWind. One palette (Electric) with Dark / Light / System; type and glow are switchable in Settings → Appearance.
- `e2e/` holds the Playwright web journeys (`make e2e` from the repo root): sign-up and onboarding, upload, post and social, For You, stats and the act bar.
- App icons, the adaptive Android layers, the favicon, the splash images (dark and light) and the in-app mark (`mark.png`, `mark-light.png`, shown by `Wordmark`) in `assets/` are drawn by `ops/scripts/make_icons.py` from the mic-check mark. The native splash (`expo-splash-screen`, configured in `app.config.ts`) stays up until the session check and fonts are ready, at most 8 s (`src/features/splash/splash.ts`).
- `android/` and `ios/` are generated (continuous native generation) and gitignored. Adding a native module (such as expo-network, expo-linear-gradient, expo-haptics or expo-splash-screen) means rebuilding the dev build: `make android`.
