# fixtures
Data used offline and in tests.
- `ticketmaster/`, `lastfm/`, `musicbrainz/` — **synthetic** responses in each provider's real response shape, generated by `python3 ops/scripts/gen_fixtures.py` (deterministic; every artist, venue and event is invented).
- `recorded/` — real responses written by `make record-fixtures`. **Gitignored**: provider terms do not allow storing them in a repository. Replay them locally with `INGESTION_FIXTURES_DIR=../fixtures/recorded make ingest`.
- `geo/uk-cities.csv` — GeoNames-derived, CC BY 4.0.
- `clips/` — synthetic test clips generated by `make clips` (gitignored).
