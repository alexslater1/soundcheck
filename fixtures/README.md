# fixtures
Data used offline and in tests.
- `ticketmaster/`, `lastfm/`, `musicbrainz/` — **synthetic** responses in each provider's real response shape, generated by `python3 ops/scripts/gen_fixtures.py` (deterministic; every artist, venue and event is invented).
- `recorded/` — real responses written by `make record-fixtures`. **Gitignored**: provider terms do not allow storing them in a repository. Replay them locally with `make ingest INGESTION_MODE=fixtures INGESTION_FIXTURES_DIR=../fixtures/recorded` (variables after `make`: a value in `.env` wins over one set before it).
- `geo/uk-cities.csv` — GeoNames-derived, CC BY 4.0.
- `clips/` — **gitignored**: the 20 synthetic test clips from `make clips`; `demo/`, 150 short synthetic clips (`python3 ops/scripts/make_clips.py --demo`); `mine/`, the owner's own concert clips and gig list for `make seed-demo` (local only: never committed, copied or deployed; see `lab/README.md`).
