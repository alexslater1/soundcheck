# fixtures/ticketmaster
Synthetic Ticketmaster Discovery API `events.json` pages (240 invented events, 43 venues, 150 artists across 14 UK cities, 3–9 Oct 2026) generated by `ops/scripts/gen_fixtures.py`. Used by `FixtureGigSource` (`INGESTION_MODE=fixtures`) and the mapper tests. Edge cases are planted on purpose and named in the script: events with no attraction, time TBA, no date, cancelled/rescheduled/postponed, venues without coordinates, a duplicated act, two price ranges. Real recordings go to `fixtures/recorded/ticketmaster/` (gitignored).
