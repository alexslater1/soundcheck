# ops
Local-stack configuration and operational scripts.
- `caddy/Caddyfile` — local edge mirroring CloudFront routing.
- `localstack/init/ready.d/` — creates the media bucket and transcode queues on start.
- `grafana/dashboards/` — dashboards as code provisioned into grafana/otel-lgtm.
- `scripts/` — smoke tests, fixture recording, clip generation.
